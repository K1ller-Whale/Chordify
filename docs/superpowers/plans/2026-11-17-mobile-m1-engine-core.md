# Mobile M1: engine core (vocab, theory, lm, decode) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the Android library module `:engine` and port `chordify_core`'s pure-arithmetic modules (`vocab`, `theory`, `lm`, `decode`) to Kotlin, proven identical to Python by golden files that Python writes.

**Architecture:** `chordify_ai/export/mobile_goldens.py` runs `chordify_core` on fixed inputs and writes the inputs plus Python's outputs as JSON into the engine's test resources. Each Kotlin package ports one Python module line for line, and its JVM unit test replays the golden inputs and compares. A Python test fails whenever `chordify_core` changes and the golden files are stale, so the two implementations cannot drift apart silently.

**Tech Stack:** Kotlin 2.1.0, Android Gradle Plugin 8.8.0 (Gradle 8.10.2 wrapper), kotlinx-serialization-json 1.7.3 (JSON parsing only, no compiler plugin), JUnit 4.13.2; Python 3.10+ with numpy for the generator.

**Spec:** [`docs/superpowers/specs/2026-11-17-mobile-on-device-design.md`](../specs/2026-11-17-mobile-on-device-design.md), milestone M1 (§9).

**This plan is M1 of six.** M2 (NNLS, resampling, file decoding) through M6 (release) each get their own plan, written when the previous milestone has landed, because what M2 learns about matching NNLS on Android decides how M3 is built.

## Global Constraints

- Module `:engine` in `Mobile/`, Android library, namespace `com.arbaba.chordifymobile.engine`; Kotlin sources under `Mobile/engine/src/main/kotlin/com/arbaba/chordifymobile/engine/`.
- `compileSdk 35`, `minSdk 33`, JVM target 17.
- Gradle 8.10.2 runs on JDK 17 or 21 only. This machine's default `java` is JDK 25, so set `JAVA_HOME` to Android Studio's bundled JDK (`C:\Program Files\Android\Android Studio\jbr`) or another JDK 17/21 before running `gradlew`.
- The existing Java `:app` module is not touched in M1 (the spec deletes it in M4).
- Each Kotlin file ports one Python file and keeps its function names in camelCase (`display_name` → `displayName`). Where Python raises `ValueError`, Kotlin throws `IllegalArgumentException`. One rename: `theory.function` is `harmonicFunction` in Kotlin.
- Python semantics that differ from Kotlin's defaults (round half to even, `str.partition`, `numpy.searchsorted`, first-index `argmax`, `numpy.median`) live in one file, `util/Py.kt`, and every port uses it.
- Golden files are generated by `python -m chordify_ai.export.mobile_goldens` and never edited by hand.
- Tolerances (spec §7.1): strings, integers and booleans must be identical; floating-point values agree to a relative 1e-9 (numpy and Kotlin sum in different orders, so the last bits differ). Change matrices: absolute 1e-12.
- Licence: the app becomes GPL-3.0-or-later (licence files land in M6). Add no dependency that is not GPL-3.0-compatible.
- Commit messages follow the repository's style: a plain sentence in the imperative ("Port chordify_core.vocab to Kotlin"), not `feat:` prefixes.

```kotlin
package com.arbaba.chordifymobile.engine.util

import java.math.BigDecimal
import java.math.RoundingMode

// The Python and numpy behaviours the port of chordify_core depends on, in one place, so
// every module rounds, searches and splits exactly as the Python code does.

/** Python's `round(x, digits)`: rounded from the exact binary value, ties to even. */
fun pyRound(x: Double, digits: Int): Double =
    if (!x.isFinite()) x else BigDecimal(x).setScale(digits, RoundingMode.HALF_EVEN).toDouble()

/** Python's `int(round(x))`: the nearest integer, ties to even. */
fun pyRoundToInt(x: Double): Int = Math.rint(x).toInt()

/** `numpy.argmax(values[:until])`: the first index of the largest value. */
fun argmax(values: DoubleArray, until: Int = values.size): Int {
    var best = 0
    for (i in 1 until until) if (values[i] > values[best]) best = i
    return best
}

/** `numpy.searchsorted(sorted, value, side="right" if right else "left")` on an ascending array. */
fun searchSorted(sorted: DoubleArray, value: Double, right: Boolean = false): Int {
    var lo = 0
    var hi = sorted.size
    while (lo < hi) {
        val mid = (lo + hi) ushr 1
        val after = if (right) sorted[mid] <= value else sorted[mid] < value
        if (after) lo = mid + 1 else hi = mid
    }
    return lo
}

/** `numpy.median`: the middle value, or the mean of the two middle values. */
fun median(values: DoubleArray): Double {
    require(values.isNotEmpty()) { "median of no values" }
    val sorted = values.sortedArray()
    val mid = sorted.size / 2
    return if (sorted.size % 2 == 1) sorted[mid] else (sorted[mid - 1] + sorted[mid]) / 2
}

/** Python's `str.partition(sep)`: (before, whether `sep` was found, after), split at the first `sep`. */
fun String.partition3(sep: Char): Triple<String, Boolean, String> {
    val at = indexOf(sep)
    return if (at < 0) Triple(this, false, "") else Triple(substring(0, at), true, substring(at + 1))
}
```

```python
def _inversions() -> list[str]:
    """Every chord type of the large vocabulary on D, over each of its chord tones."""
    return [f"D:{quality}/{degree}" for quality in vocab.LARGE_QUALITIES
            for degree in sorted(vocab.parse(f"D:{quality}").degrees - {"1"})]


def _chord_row(label: str) -> dict:
    chord = vocab.parse(label)
    row = {
        "label": label, "parsed": chord.label, "root": chord.root, "bass": chord.bass,
        "degrees": sorted(chord.degrees), "pitch_classes": sorted(chord.pitch_classes),
        "third": chord.third, "fifth": chord.fifth, "seventh": chord.seventh, "has_sixth": chord.has_sixth,
        "triad": vocab.triad(chord), "chord_tones": vocab.chord_tones(label),
        "display": {"auto": vocab.display_name(label), "flats": vocab.display_name(label, True),
                    "sharps": vocab.display_name(label, False)},
        "transpose": {"-3": vocab.transpose(label, -3), "-3b": vocab.transpose(label, -3, True),
                      "5": vocab.transpose(label, 5), "5b": vocab.transpose(label, 5, True)},
    }
    for name, vocabulary in vocab.VOCABULARIES.items():
        row[name] = {"encode": vocabulary.encode(label), "reduce": vocab.reduce(label, vocabulary),
                     "reduce_keep_bass": vocab.reduce_keep_bass(label, vocabulary),
                     "simplify": vocab.simplify(label, vocabulary)}
    return row


def vocab_golden() -> dict:
    for label in INVALID_LABELS:
        assert "error" in _attempt(vocab.parse, label), f"{label!r} parses; it does not belong in INVALID_LABELS"
    labels = list(dict.fromkeys(list(vocab.LARGE.labels) + _inversions() + EXTRA_LABELS))
    rows = [_chord_row(label) for label in labels]
    names = list(dict.fromkeys(DISPLAY_NAMES + [r["display"]["auto"] for r in rows]
                               + [r["display"]["flats"] for r in rows]))
    return {
        "chords": rows,
        "invalid": INVALID_LABELS,
```

```kotlin
package com.arbaba.chordifymobile.engine.vocab

import com.arbaba.chordifymobile.engine.util.partition3
import java.util.concurrent.ConcurrentHashMap

// Port of chordify_core/vocab.py: Harte chord labels and pitch-class maths. Everything works
// on intervals and pitch classes, never on label strings, so enharmonic spellings (Bb vs A#)
// cannot split a class. Harte syntax: root[:shorthand][(degrees)][/bass], e.g. A:min7,
// C:maj/3, G:sus4(b7,9), D:(1,b3,5), N (no chord), X (unknown).

const val NO_CHORD = "N"
const val UNKNOWN = "X"

val SHARP_NAMES = listOf("C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B")
val FLAT_NAMES = listOf("C", "Db", "D", "Eb", "E", "F", "Gb", "G", "Ab", "A", "Bb", "B")
private val NATURALS = mapOf('C' to 0, 'D' to 2, 'E' to 4, 'F' to 5, 'G' to 7, 'A' to 9, 'B' to 11)

// Scale degree -> semitones above the root (compound degrees keep their octave).
private val DEGREE_SEMITONES = mapOf(1 to 0, 2 to 2, 3 to 4, 4 to 5, 5 to 7, 6 to 9, 7 to 11, 8 to 12, 9 to 14,
                                     10 to 16, 11 to 17, 12 to 19, 13 to 21)

// Harte shorthands as degree lists.
val SHORTHANDS: Map<String, List<String>> = mapOf(
    "maj" to listOf("1", "3", "5"),
    "min" to listOf("1", "b3", "5"),
    "dim" to listOf("1", "b3", "b5"),
    "aug" to listOf("1", "3", "#5"),
    "maj7" to listOf("1", "3", "5", "7"),
    "min7" to listOf("1", "b3", "5", "b7"),
    "7" to listOf("1", "3", "5", "b7"),
    "dim7" to listOf("1", "b3", "b5", "bb7"),
    "hdim7" to listOf("1", "b3", "b5", "b7"),
    "minmaj7" to listOf("1", "b3", "5", "7"),
    "maj6" to listOf("1", "3", "5", "6"),
    "min6" to listOf("1", "b3", "5", "6"),
    "9" to listOf("1", "3", "5", "b7", "9"),
    "maj9" to listOf("1", "3", "5", "7", "9"),
    "min9" to listOf("1", "b3", "5", "b7", "9"),
    "11" to listOf("1", "3", "5", "b7", "9", "11"),
    "maj11" to listOf("1", "3", "5", "7", "9", "11"),
    "min11" to listOf("1", "b3", "5", "b7", "9", "11"),
    "13" to listOf("1", "3", "5", "b7", "9", "11", "13"),
    "maj13" to listOf("1", "3", "5", "7", "9", "11", "13"),
    "min13" to listOf("1", "b3", "5", "b7", "9", "11", "13"),
    "sus2" to listOf("1", "2", "5"),
    "sus4" to listOf("1", "4", "5"),
    "5" to listOf("1", "5"),
    "1" to listOf("1"),
)

/** 'C' -> 0, 'Bb' -> 10, 'E#' -> 5, 'Cbb' -> 10. */
fun noteToPc(name: String): Int {
    if (name.isEmpty() || name[0] !in NATURALS) throw IllegalArgumentException("not a note name: '$name'")
    var pc = NATURALS.getValue(name[0])
    for (accidental in name.substring(1)) {
        pc += when (accidental) {
            '#' -> 1
            'b' -> -1
            else -> throw IllegalArgumentException("not a note name: '$name'")
        }
    }
    return Math.floorMod(pc, 12)
}

fun pcToName(pc: Int, flats: Boolean = false): String = (if (flats) FLAT_NAMES else SHARP_NAMES)[Math.floorMod(pc, 12)]

/** 'b3' -> 3, '#11' -> 18, 'bb7' -> 9. */
fun degreeToSemitones(degree: String): Int {
    val stripped = degree.trimStart('b', '#')
    val modifier = degree.substring(0, degree.length - stripped.length)
    val base = stripped.toIntOrNull()?.let { DEGREE_SEMITONES[it] }
        ?: throw IllegalArgumentException("not a scale degree: '$degree'")
    return base + modifier.count { it == '#' } - modifier.count { it == 'b' }
}

/** A parsed chord. [root] is null for N and X; [bass] is absolute and equals [root] in root position. */
data class Chord(val label: String, val root: Int?, val degrees: Set<String>, val bass: Int?) {
    val isChord: Boolean get() = root != null

    /** Sounding pitch classes; a slash bass is a chord tone too (Harte semantics). */
    val pitchClasses: Set<Int>
        get() {
            val r = root ?: return emptySet()
            return degrees.map { Math.floorMod(r + degreeToSemitones(it), 12) }.toSet() + bass!!
        }

    /** "maj", "min" or null (sus and power chords). */
    val third: String?
        get() = when {
            "3" in degrees -> "maj"
            "b3" in degrees -> "min"
            else -> null
        }

    /** "perfect", "dim", "aug" or null. */
    val fifth: String?
        get() = when {
            "5" in degrees -> "perfect"
            "b5" in degrees -> "dim"
            "#5" in degrees -> "aug"
            else -> null
        }

    /** "maj" (7), "min" (b7), "dim" (bb7) or null. */
    val seventh: String?
        get() = when {
            "7" in degrees -> "maj"
            "b7" in degrees -> "min"
            "bb7" in degrees -> "dim"
            else -> null
        }

    val hasSixth: Boolean get() = "6" in degrees && seventh == null
}

private val parsed = ConcurrentHashMap<String, Chord>()

/** Parse a Harte label. Throws IllegalArgumentException for malformed labels. */
fun parse(label: String): Chord = parsed[label] ?: parseUncached(label).also { parsed[label] = it }

private fun parseUncached(raw: String): Chord {
    val label = raw.trim()
    if (label == NO_CHORD || label == UNKNOWN) return Chord(label, null, emptySet(), null)
    val (body, _, bassPart) = label.partition3('/')
    val (rootPart, hasQuality, qualityText) = body.partition3(':')
    val root = noteToPc(rootPart)
    val quality = if (hasQuality) qualityText else "maj"
    val (shorthand, paren, extra) = quality.partition3('(')
    if (paren && !extra.endsWith(")")) throw IllegalArgumentException("unbalanced parentheses in '$label'")
    if (shorthand.isNotEmpty() && shorthand !in SHORTHANDS) {
        throw IllegalArgumentException("unknown shorthand '$shorthand' in '$label'")
    }
    if (shorthand.isEmpty() && !paren) throw IllegalArgumentException("missing quality in '$label'")
    val degrees = SHORTHANDS[shorthand].orEmpty().toMutableSet()
    if (paren) {
        for (item in extra.dropLast(1).split(',').map { it.trim() }.filter { it.isNotEmpty() }) {
            if (item.startsWith("*")) {
                degrees.remove(item.substring(1))
            } else {
                degreeToSemitones(item) // validate
                degrees.add(item)
            }
        }
    }
    if (shorthand.isEmpty()) degrees.add("1")
    val bass = if (bassPart.isNotEmpty()) Math.floorMod(root + degreeToSemitones(bassPart), 12) else root
    return Chord(label, root, degrees.toSet(), bass)
}

/** Triad quality: maj, min, dim, aug, sus2, sus4, 5 (power), 1 (single note) or null. */
fun triad(chord: Chord): String? {
    if (!chord.isChord) return null
    val third = chord.third
    val fifth = chord.fifth
    if (third == "maj") return if (fifth == "aug") "aug" else "maj"
    if (third == "min") return if (fifth == "dim") "dim" else "min"
    if ("4" in chord.degrees && fifth == "perfect") return "sus4"
    if ("2" in chord.degrees && fifth == "perfect") return "sus2"
    if (fifth == "perfect") return "5"
    return "1"
}
```

```kotlin
package com.arbaba.chordifymobile.engine.vocab

// Vocabulary tiers and label arithmetic from chordify_core/vocab.py.

val LARGE_QUALITIES = listOf("maj", "min", "dim", "aug", "maj6", "min6", "7", "maj7", "min7",
                             "dim7", "hdim7", "minmaj7", "sus2", "sus4")

private fun reduceMajmin(chord: Chord): String? = triad(chord).takeIf { it == "maj" || it == "min" }

private fun reduceSevenths(chord: Chord): String? = when (triad(chord)) {
    "maj" -> when (chord.seventh) {
        null -> "maj"
        "min" -> "7"
        "maj" -> "maj7"
        else -> null
    }
    "min" -> when (chord.seventh) {
        null -> "min"
        "min" -> "min7"
        else -> null
    }
    else -> null
}

private fun reduceLarge(chord: Chord): String? = when (triad(chord) to chord.seventh) {
    "maj" to null -> if (chord.hasSixth) "maj6" else "maj"
    "min" to null -> if (chord.hasSixth) "min6" else "min"
    "maj" to "min" -> "7"
    "maj" to "maj" -> "maj7"
    "min" to "min" -> "min7"
    "min" to "maj" -> "minmaj7"
    "dim" to null -> "dim"
    "dim" to "dim" -> "dim7"
    "dim" to "min" -> "hdim7"
    "aug" to null, "aug" to "min", "aug" to "maj" -> "aug"
    "sus2" to null, "sus2" to "min" -> "sus2"
    "sus4" to null, "sus4" to "min" -> "sus4"
    else -> null
}

/** A fixed list of chord classes: class i < 12·Q is root i % 12 with quality qualities[i / 12]; N is the last. */
class Vocabulary(val name: String, val qualities: List<String>) {
    val size: Int = 12 * qualities.size + 1
    val noChord: Int = size - 1
    val labels: List<String> = List(12 * qualities.size) { "${SHARP_NAMES[it % 12]}:${qualities[it / 12]}" } + NO_CHORD

    fun reduceQuality(chord: Chord): String? = when (name) {
        "majmin" -> reduceMajmin(chord)
        "sevenths" -> reduceSevenths(chord)
        "large" -> reduceLarge(chord)
        else -> throw IllegalStateException("unknown vocabulary '$name'")
    }

    /** Class index, or null when the chord is outside the vocabulary (X). */
    fun encode(label: String): Int? {
        val chord = parse(label)
        if (chord.label == NO_CHORD) return noChord
        val root = chord.root ?: return null
        val quality = reduceQuality(chord) ?: return null
        return qualities.indexOf(quality) * 12 + root
    }

    fun decode(index: Int): String = labels[index]

    fun transposeIndex(index: Int, semitones: Int): Int =
        if (index == noChord) index else (index / 12) * 12 + Math.floorMod(index % 12 + semitones, 12)

    fun rootOf(index: Int): Int? = if (index == noChord) null else index % 12

    fun qualityOf(index: Int): String? = if (index == noChord) null else qualities[index / 12]
}

val MAJMIN = Vocabulary("majmin", listOf("maj", "min"))
val SEVENTHS = Vocabulary("sevenths", listOf("maj", "min", "7", "maj7", "min7"))
val LARGE = Vocabulary("large", LARGE_QUALITIES)
val VOCABULARIES: Map<String, Vocabulary> = listOf(MAJMIN, SEVENTHS, LARGE).associateBy { it.name }

/** Each tier's chord types include the previous tier's. */
val TIERS = listOf("majmin", "sevenths", "large")

/** Map any Harte label onto a vocabulary tier, returning X when it has no class. */
fun reduce(label: String, vocabulary: Vocabulary = MAJMIN): String =
    vocabulary.encode(label)?.let(vocabulary::decode) ?: UNKNOWN

/** [label] played over [bassPc] when that note is one of its chord tones other than the root
 *  ('C:maj' + E -> 'C:maj/3', 'G:7' + F -> 'G:7/b7'); otherwise [label] unchanged. */
fun withBass(label: String, bassPc: Int): String {
    val chord = parse(label)
    val root = chord.root ?: return label
    if (Math.floorMod(bassPc, 12) == root) return label
    val interval = Math.floorMod(bassPc - root, 12)
    val degree = chord.degrees.sorted().firstOrNull { Math.floorMod(degreeToSemitones(it), 12) == interval }
        ?: return label
    return "${label.substringBefore('/')}/$degree"
}

/** Name [label] with the chord types of a coarser vocabulary, for display: like [reduceKeepBass],
 *  but a chord the tier cannot represent falls back to its major/minor family by its third
 *  ('B:hdim7' -> 'B:min' in majmin, 'C:sus4' -> 'C:maj') instead of X. */
fun simplify(label: String, vocabulary: Vocabulary): String {
    val simplified = reduceKeepBass(label, vocabulary)
    val chord = parse(label)
    if (simplified != UNKNOWN || !chord.isChord) return simplified
    val family = "${SHARP_NAMES[chord.root!!]}:${if (chord.third == "min") "min" else "maj"}"
    return withBass(family, chord.bass!!)
}

/** Like [reduce], but an inversion survives while its bass is still a chord tone of the reduced
 *  chord: 'C:maj7/3' -> 'C:maj/3' in majmin, while 'C:maj7/7' -> 'C:maj'. */
fun reduceKeepBass(label: String, vocabulary: Vocabulary): String {
    val reduced = reduce(label, vocabulary)
    val chord = parse(label)
    if (reduced == UNKNOWN || reduced == NO_CHORD || !chord.isChord || chord.bass == chord.root) return reduced
    return withBass(reduced, chord.bass!!)
}

/** The root as written at the start of a label: 'Bb:min7' -> 'Bb'. */
internal fun rootText(label: String): String {
    var end = 1
    while (end < label.length && label[end] in "#b") end++
    return label.take(end)
}

/** Transpose a Harte label, keeping its quality, degrees and bass interval. */
fun transpose(label: String, semitones: Int, flats: Boolean = false): String {
    val chord = parse(label)
    val root = chord.root ?: return chord.label
    val stripped = label.trim()
    return pcToName(root + semitones, flats) + stripped.substring(rootText(stripped).length)
}

/** 12 zeros and ones: the chord's pitch classes (absolute). */
fun chordTones(label: String): List<Int> {
    val pitchClasses = parse(label).pitchClasses
    return List(12) { if (it in pitchClasses) 1 else 0 }
}
```

```kotlin
 *  [flats] spells the slash bass; null takes it from how the root is written. */
fun displayName(label: String, flats: Boolean? = null): String {
    val chord = parse(label)
    if (chord.label == NO_CHORD) return "N.C."
    if (chord.root == null) return "?"
    val (body, _, bassPart) = label.trim().partition3('/')
    val (rootText, hasQuality, qualityText) = body.partition3(':')
    val useFlats = flats ?: ('b' in rootText.drop(1))
    val quality = if (hasQuality) qualityText else "maj"
    val suffix = SPECIAL_DISPLAY[quality] ?: run {
        val (shorthand, paren, extra) = quality.partition3('(')
        (DISPLAY_SUFFIX[shorthand] ?: shorthand) + if (paren) "(${extra.dropLast(1)})" else ""
    }
    var text = rootText + suffix
    if (bassPart.isNotEmpty() && chord.bass != chord.root) text += "/" + pcToName(chord.bass!!, useFlats)
    return text
}

    "mMaj7" to "minmaj7", "6/9" to "maj6(9)", "aug7" to "aug(b7)",
)
private val SEMITONE_DEGREE = listOf("1", "b2", "2", "b3", "3", "4", "b5", "5", "b6", "6", "b7", "7")

/** Lead-sheet chord name -> Harte label: 'Em' -> 'E:min', 'Bm7' -> 'B:min7', 'C/E' -> 'C:maj/3',
 *  'A7sus4' -> 'A:sus4(b7)', 'N.C.' -> 'N'. Harte labels pass through unchanged. */
fun parseDisplay(name: String): String {
    val text = name.trim()
    if (text.uppercase() in setOf("N", "N.C.", "NC")) return NO_CHORD
    if (':' in text) {
        parse(text)
        return text
    }
    val rootText = rootText(text)
    val root = noteToPc(rootText)
    val (body, slash, bassText) = text.substring(rootText.length).partition3('/')
    val quality = LEADSHEET[body] ?: throw IllegalArgumentException("unknown chord name: '$text'")
    var label = "$rootText:$quality"
    if (slash) {
        if (body == "6" && bassText == "9") return "$rootText:maj6(9)" // 6/9 chord, not a slash chord
        label += "/" + SEMITONE_DEGREE[Math.floorMod(noteToPc(bassText) - root, 12)]
    }
    parse(label)
    return label
}
```

```kotlin
// Keys conventionally written with flats.
private val FLAT_MAJOR = setOf(5, 10, 3, 8, 1) // F Bb Eb Ab Db (F# major preferred over Gb)
private val FLAT_MINOR = setOf(2, 7, 0, 5, 10, 3) // D G C F Bb Eb

// Krumhansl & Kessler (1982) key profiles.
private val KK_MAJOR = doubleArrayOf(6.35, 2.23, 3.48, 2.33, 4.38, 4.09, 2.52, 5.19, 2.39, 3.66, 2.29, 2.88)
private val KK_MINOR = doubleArrayOf(6.33, 2.68, 3.52, 5.38, 2.60, 3.53, 2.54, 4.75, 3.98, 2.69, 3.34, 3.17)

data class Key(val tonic: Int, val mode: String = "major") {
    val flats: Boolean get() = tonic in (if (mode == "major") FLAT_MAJOR else FLAT_MINOR)
    val tonicName: String get() = pcToName(tonic, flats)
    val name: String get() = "$tonicName $mode"
    val scale: List<Int> get() = if (mode == "major") MAJOR_SCALE else MINOR_SCALE_EXTENDED

    fun contains(pitchClasses: Iterable<Int>): Boolean {
        val inKey = scale.map { Math.floorMod(tonic + it, 12) }.toSet()
        return pitchClasses.all { it in inKey }
    }

    fun spell(pc: Int): String = pcToName(pc, flats)
}

private val KEY_PATTERN = Regex("([A-G][#b]*)\\s*(?::?\\s*(maj|major|min|minor|m))?", RegexOption.IGNORE_CASE)

/** 'D', 'D:maj', 'D major', 'Bb:min', 'F#m', 'A minor' -> Key. */
fun parseKey(text: String): Key {
    val trimmed = text.trim()
    val match = KEY_PATTERN.matchEntire(trimmed) ?: throw IllegalArgumentException("not a key: '$trimmed'")
    val mode = (match.groups[2]?.value ?: "maj").lowercase()
    return Key(noteToPc(match.groupValues[1]), if (mode in setOf("min", "minor", "m")) "minor" else "major")
}

val ALL_KEYS: List<Key> = listOf("major", "minor").flatMap { mode -> (0 until 12).map { Key(it, mode) } }

/** Correlation of a 12-bin pitch-class distribution with every key's Krumhansl–Kessler profile, best first. */
fun keyScores(chroma: DoubleArray): List<Pair<Key, Double>> {
    val varies = std(chroma) > 0
    return ALL_KEYS.map { key ->
        val profile = roll(if (key.mode == "major") KK_MAJOR else KK_MINOR, key.tonic)
        key to (if (varies) correlation(chroma, profile) else 0.0)
    }.sortedByDescending { it.second }
}

/** Key from [(label, duration), ...]: duration-weighted chord tones correlated with key profiles,
 *  plus a bonus for keys whose tonic chord opens or closes the song. Returns (key, confidence in
 *  0..1: the softmax margin over the 24 candidates). */
fun estimateKeyFromChords(chords: List<Pair<String, Double>>): Pair<Key, Double> {
    val real = chords.map { (label, duration) -> parse(label) to duration }.filter { it.first.isChord }
    if (real.isEmpty()) return Key(0, "major") to 0.0
    val histogram = DoubleArray(12)
    for ((chord, duration) in real) {
        for (pc in chord.pitchClasses) histogram[pc] += duration
        histogram[chord.root!!] += 0.5 * duration
    }
    val ends = listOf(real.first().first, real.last().first)
    val scored = keyScores(histogram).map { (key, base) ->
        var score = base
        for (chord in ends) {
            if (chord.root == key.tonic && triad(chord) == (if (key.mode == "major") "maj" else "min")) score += 0.1
        }
        key to score
    }.sortedByDescending { it.second }
    val values = scored.map { it.second * 20.0 }
    val top = values.max()
    val weights = values.map { exp(it - top) }
    return scored[0].first to weights[0] / weights.sum()
}

/** numpy's `values.std()`: the population standard deviation. */
private fun std(values: DoubleArray): Double {
    val mean = values.sum() / values.size
    return sqrt(values.sumOf { (it - mean) * (it - mean) } / values.size)
}

/** numpy's `np.roll(profile, shift)`. */
private fun roll(profile: DoubleArray, shift: Int): DoubleArray =
    DoubleArray(profile.size) { profile[Math.floorMod(it - shift, profile.size)] }

/** numpy's `np.corrcoef(x, y)[0, 1]`, computed in the same order. */
private fun correlation(x: DoubleArray, y: DoubleArray): Double {
    val n = x.size
    val mx = x.sum() / n
    val my = y.sum() / n
    var sxy = 0.0
    var sxx = 0.0
    var syy = 0.0
    for (i in 0 until n) {
        val dx = x[i] - mx
        val dy = y[i] - my
        sxy += dx * dy
        sxx += dx * dx
        syy += dy * dy
    }
    val dof = (n - 1).toDouble()
    return ((sxy / dof) / sqrt(sxx / dof) / sqrt(syy / dof)).coerceIn(-1.0, 1.0)
}
```

```kotlin
fun roman(label: String, key: Key, withQuality: Boolean = false): String? {
    val chord = parse(label)
    val root = chord.root ?: return null
    val secondary = secondaryDominant(label, key)
    if (secondary != null) {
        val suffix = if (withQuality) qualitySuffix(chord) else ""

        return if (suffix.isNotEmpty()) "$head$suffix/$target" else secondary
    }

    val kind = triad(chord)
    if (kind == "min" || kind == "dim") numeral = numeral.replace(NUMERAL_LETTERS) { it.value.lowercase() }
    if (kind == "dim") {
        numeral += if (chord.seventh == "min") "ø" else "°"
    } else if (kind == "aug") {
        numeral += "+"
    }
    if (withQuality) numeral += qualitySuffix(chord)
    return numeral
}

/** What follows the numeral: 7, maj7, 6, sus4, ø7 / °7 (the ø/° is already on the numeral),
 *  (maj7) for a minor-major seventh. */
private fun qualitySuffix(chord: Chord): String {
    val kind = triad(chord)
    val seventh = chord.seventh
    return when {
        kind == "sus2" || kind == "sus4" -> (if (seventh == "min") "7" else "") + kind
        kind == "min" && seventh == "maj" -> "(maj7)"
        seventh == "min" || seventh == "dim" -> "7"
        seventh == "maj" -> "maj7"
        (kind == "maj" || kind == "min") && chord.hasSixth -> "6"
        else -> ""
    }
}

    val chord = parse(label)

    if (target == 0 || target !in key.scale) return null
    val name = SECONDARY_TARGETS.getValue(key.mode)[target] ?: return null
    return "V/$name"
}

        "min" -> "$name Dorian"
        "sus2", "sus4", "5" -> "$name Mixolydian"

        "aug" -> "$name whole tone"
        else -> null
    }
}

    val parallel = Key(key.tonic, if (key.mode == "major") "minor" else "major")
    return if (isDiatonic(label, parallel)) parallel.name else null
}

)

/** Short theory explanation of a chord change, or null if nothing notable. */
fun transitionReason(prevLabel: String, nextLabel: String, key: Key): String? {
    val a = baseNumeral(roman(prevLabel, key))
    val b = baseNumeral(roman(nextLabel, key))
    if (a == null || b == null || a == b) return null
    if (b.startsWith("V/")) return "secondary dominant $b leading to ${b.substring(2)}"
    if (a.startsWith("V/")) return "$a resolves"
    TRANSITIONS[a to b]?.let { return it }
    borrowedFrom(nextLabel, key)?.let { return "$b borrowed from $it" }
    val fa = harmonicFunction(prevLabel, key)
    val fb = harmonicFunction(nextLabel, key)
    if (fa != null && fb != null && fa != fb && fa != "borrowed" && fb != "borrowed") return "$fa → $fb"
    return null
}

fun cadence(prevLabel: String, nextLabel: String, key: Key): String? {
    val a = baseNumeral(roman(prevLabel, key)) ?: return null
    val b = baseNumeral(roman(nextLabel, key)) ?: return null
    return when {
        a == "V" && b.uppercase() == "I" -> "authentic"
        a.uppercase() == "IV" && b.uppercase() == "I" -> "plagal"
        a == "V" && b.uppercase() == "VI" -> "deceptive"
        b == "V" && a != "V" -> "half"
        else -> null
    }
}
```

```kotlin
package com.arbaba.chordifymobile.engine.theory

// Repeating progressions from chordify_core/theory.py.

data class ProgressionPattern(val roman: List<String>, val name: String?, val count: Int)

// Several rotations of a loop can have names (I–V–vi–IV and vi–IV–I–V); this order decides
// which one is shown, so a loop is always presented the same way.
val NAMED_PROGRESSIONS: Map<List<String>, String> = linkedMapOf(
    listOf("I", "V", "vi", "IV") to "I–V–vi–IV (the “Axis” progression)",
    listOf("I", "vi", "IV", "V") to "I–vi–IV–V (the ’50s progression)",
    listOf("vi", "IV", "I", "V") to "vi–IV–I–V (Axis, minor rotation)",
    listOf("I", "IV", "V", "IV") to "I–IV–V–IV (rock three-chord loop)",
    listOf("ii", "V", "I") to "ii–V–I",
    listOf("i", "VII", "VI", "V") to "i–VII–VI–V (Andalusian cadence)",
    listOf("I", "bVII", "IV", "I") to "I–bVII–IV–I (Mixolydian vamp)",
    listOf("I", "bVII", "IV") to "I–bVII–IV (Mixolydian vamp)",
    listOf("I", "IV", "V") to "I–IV–V (three-chord trick)",
)

// Python's ordering of tuples of strings.
private val LEXICOGRAPHIC = Comparator<List<String>> { a, b ->
    for (i in 0 until minOf(a.size, b.size)) {
        val c = a[i].compareTo(b[i])
        if (c != 0) return@Comparator c
    }
    a.size - b.size
}

private fun rotations(pattern: List<String>): List<List<String>> = pattern.indices.map { pattern.drop(it) + pattern.take(it) }

/** True if [small] is a contiguous piece of [loop] played cyclically. */
private fun insideLoop(small: List<String>, loop: List<String>): Boolean {
    val doubled = loop + loop
    return small.size <= loop.size && loop.indices.any { doubled.subList(it, it + small.size) == small }
}

/** Repeating loops in a chord-change sequence (Roman numerals), rotations merged, most frequent first. */
fun findPatterns(numerals: List<String?>, lengths: List<Int> = listOf(4, 3), minCount: Int = 3,
                 limit: Int = 3): List<ProgressionPattern> {
    val base = numerals.filter { !it.isNullOrEmpty() }.map { baseNumeral(it)!! }
    val seq = base.filterIndexed { i, n -> i == 0 || base[i - 1] != n }
    val found = ArrayList<ProgressionPattern>()
    val covered = LinkedHashSet<List<String>>()
    for (length in lengths) {
        val grams = LinkedHashMap<List<String>, Int>()
        for (i in 0..seq.size - length) {
            val gram = seq.subList(i, i + length).toList()
            grams[gram] = (grams[gram] ?: 0) + 1
        }
        val classes = LinkedHashMap<List<String>, LinkedHashMap<List<String>, Int>>()
        for ((gram, count) in grams) {
            if (gram.toSet().size < 2) continue
            val canonical = rotations(gram).minWithOrNull(LEXICOGRAPHIC)!!
            classes.getOrPut(canonical) { LinkedHashMap() }[gram] = count
        }
        for ((canonical, members) in classes) {
            var (rotation, count) = members.entries.first().toPair()
            for ((gram, n) in members) if (n > count) { rotation = gram; count = n }
            if (count < minCount || covered.any { insideLoop(rotation, it) }) continue
            val rotationSet = rotations(rotation).toSet()
            val named = NAMED_PROGRESSIONS.keys.firstOrNull { it in rotationSet }
            if (named != null) rotation = named
            found.add(ProgressionPattern(rotation, named?.let { NAMED_PROGRESSIONS.getValue(it) }, count))
            covered.add(canonical)
        }
    }
    return found.sortedWith(compareByDescending<ProgressionPattern> { it.count }.thenByDescending { it.roman.size })
        .take(limit)
}
```

```kotlin
package com.arbaba.chordifymobile.engine.lm

import com.arbaba.chordifymobile.engine.theory.Key
import com.arbaba.chordifymobile.engine.vocab.NO_CHORD
import com.arbaba.chordifymobile.engine.vocab.Vocabulary
import com.arbaba.chordifymobile.engine.vocab.parse
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.double
import kotlinx.serialization.json.int
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive
import java.io.InputStream
import java.util.zip.GZIPInputStream

// Port of chordify_core/lm.py: what chord comes next? A key-relative n-gram trained on many
// songs, mixed with a song cache that looks for the current context earlier in the same song.
// Tokens are key-relative: "<semitones above the tonic>:<maj|min>", e.g. V = "7:maj",
// vi = "9:min". The same model supplies the decoder's chord-change matrix.

val TOKENS: List<String> = listOf("maj", "min").flatMap { quality -> (0 until 12).map { "$it:$quality" } }

/** Key-relative token of a chord label; null for N and X. Sus, power and aug count as major,
 *  dim as minor (the third decides). */
fun token(label: String, key: Key): String? {
    val chord = parse(label)
    val root = chord.root ?: return null
    val quality = if (chord.third == "min") "min" else "maj"
    return "${Math.floorMod(root - key.tonic, 12)}:$quality"
}

/** Absolute Harte label for a token in a key: '9:min' in D -> 'B:min'. */
fun tokenLabel(tok: String, key: Key): String {
    val (degree, quality) = tok.split(":")
    return "${key.spell(Math.floorMod(key.tonic + degree.toInt(), 12))}:$quality"
}

fun <T> dedupe(seq: List<T>): List<T> = seq.filterIndexed { i, x -> i == 0 || seq[i - 1] != x }

data class Candidate(val token: String, val p: Double, val cacheCount: Int)

class NgramProgressionModel(
    val order: Int,
    val minCount: Int,
    val cacheWeight: Double,
    val maxContext: Int,
    val counts: List<Map<List<String>, Map<String, Int>>>,
) {
    companion object {
        /** Read `model.json.gz` as written by Python's `NgramProgressionModel.save`. */
        fun load(gzipped: InputStream): NgramProgressionModel =
            GZIPInputStream(gzipped).bufferedReader(Charsets.UTF_8).use {
                fromJson(Json.parseToJsonElement(it.readText()).jsonObject)
            }

        fun fromJson(data: JsonObject): NgramProgressionModel {
            val counts = data.getValue("counts").jsonArray.map { level ->
                level.jsonObject.entries.associate { (context, followers) ->
                    val tokens = if (context.isEmpty()) emptyList() else context.split(' ')
                    tokens to followers.jsonObject.entries.associate { (tok, n) -> tok to n.jsonPrimitive.int }
                }
            }
            return NgramProgressionModel(data.getValue("order").jsonPrimitive.int,
                                         data.getValue("min_count").jsonPrimitive.int,
                                         data.getValue("cache_weight").jsonPrimitive.double,
                                         data.getValue("max_context").jsonPrimitive.int, counts)
        }
    }

    /** Longest context seen at least [minCount] times, smoothed over all tokens. */
    fun corpusDistribution(history: List<String>): Map<String, Double> {
        val h = dedupe(history)
        var chosen: Map<String, Int>? = null
        for (k in minOf(order - 1, h.size) downTo 0) {
            val context = if (k > 0) h.subList(h.size - k, h.size).toList() else emptyList()
            val counts = this.counts[k][context]
            if (counts != null && counts.values.sum() >= minCount) {
                chosen = counts
                break
            }
        }
        val dist = LinkedHashMap<String, Double>()
        for (t in TOKENS) dist[t] = 1e-3
        if (chosen != null) {
            val total = chosen.values.sum().toDouble()
            for ((t, c) in chosen) dist[t] = (dist[t] ?: 1e-3) + c / total
        }
        if (h.isNotEmpty()) dist[h.last()] = 0.0 // a "change" is never to the same chord
        val norm = dist.values.sum()
        for (t in dist.keys) dist[t] = dist.getValue(t) / norm
        return dist
    }

    /** What followed the longest matching context earlier in this song, and that context's length. */
    fun cacheCounts(history: List<String>): Pair<Map<String, Int>, Int> {
        val h = dedupe(history)
        val n = h.size
        for (k in minOf(maxContext, n - 1) downTo 1) {
            val context = h.subList(n - k, n)
            val followers = LinkedHashMap<String, Int>()
            for (j in k until n) {
                if (h.subList(j - k, j) == context) followers[h[j]] = (followers[h[j]] ?: 0) + 1
            }
            followers.remove(h.last())
            if (followers.isNotEmpty()) return followers to k
        }
        return LinkedHashMap<String, Int>() to 0
    }

    fun distribution(history: List<String>): Pair<Map<String, Double>, Map<String, Int>> {
        val corpus = corpusDistribution(history)
        val (cache, _) = cacheCounts(history)
        if (cache.isEmpty()) return corpus to cache
        val total = cache.values.sum().toDouble()
        val mixed = LinkedHashMap<String, Double>()
        for ((t, p) in corpus) mixed[t] = (1 - cacheWeight) * p
        for ((t, c) in cache) mixed[t] = (mixed[t] ?: 0.0) + cacheWeight * c / total
        return mixed to cache
    }

    fun top(history: List<String>, k: Int = 3): List<Candidate> {
        val (dist, cache) = distribution(history)
        return dist.entries.sortedByDescending { it.value }.take(k).map { (t, p) -> Candidate(t, p, cache[t] ?: 0) }
    }

    /** (V, V) chord-change probabilities for the decoder: bigram corpus statistics in [key], shared
     *  equally among classes with the same token; zero diagonal. Tokens are key-relative root +
     *  major/minor family, so C -> C7 is no change for the n-gram; in larger vocabularies those
     *  same-token changes get [sameTokenShare] of each row. */
    fun changeMatrix(vocabulary: Vocabulary, key: Key, sameTokenShare: Double = 0.05): Array<DoubleArray> {
        val labels = vocabulary.labels
        val tokens = labels.map { if (it != NO_CHORD) token(it, key) else null }
        val perToken = tokens.filterNotNull().groupingBy { it }.eachCount()
        val size = labels.size
        val matrix = Array(size) { DoubleArray(size) }
        for (i in 0 until size) {
            val ti = tokens[i]
            val row = matrix[i]
            if (ti == null) {
                row.fill(1.0)
            } else {
                val dist = corpusDistribution(listOf(ti))
                for (j in 0 until size) {
                    val tj = tokens[j]
                    row[j] = if (tj == null) 0.02 else (dist[tj] ?: 1e-3) / perToken.getValue(tj)
                }
            }
            row[i] = 0.0
            val sum = row.sum()
            for (j in row.indices) row[j] /= sum
            if (ti == null) continue
            val same = (0 until size).filter { tokens[it] == ti && it != i }
            if (same.isEmpty()) continue
            val sameSet = same.toSet()
            val others = (0 until size).filter { it != i && it !in sameSet }
            val scale = (1 - sameTokenShare) / others.sumOf { row[it] }
            for (j in others) row[j] *= scale
            for (j in same) row[j] = sameTokenShare / same.size
        }
        return matrix
    }
}
```

```kotlin
import com.arbaba.chordifymobile.engine.theory.Key
import com.arbaba.chordifymobile.engine.theory.roman

// High-level prediction with explanations, from chordify_core/lm.py.

data class Prediction(
    val label: String,
    val display: String,
    val roman: String?,
    val p: Double,
    val reason: String,
    val cacheCount: Int = 0,
    val expectedBeats: Double? = null,
)

data class PriorEntry(val roman: String?, val p: Double)

/** Top-[k] next chords after [history] (absolute Harte labels, chord changes in order).
 *
 *  Returns (predictions, corpus-only prior) so a UI can show how much the song's own history
 *  changed the answer. When a predicted chord already occurred in the song, its full label (Bm7
 *  rather than Bm) is used, and `expectedBeats` is its median length so far when [historyBeats]
 *  is given. As in Python, [historyBeats] is indexed like the history with N and X removed. */
fun predictNext(model: NgramProgressionModel, history: List<String>, key: Key, k: Int = 3,
                historyBeats: List<Double>? = null): Pair<List<Prediction>, List<PriorEntry>> {
    val real = history.filter { parse(it).isChord }
    val tokens = real.map { token(it, key)!! }
    val seen = LinkedHashMap<String, String>()
    val lengths = HashMap<String, MutableList<Double>>()
    for ((i, label) in real.withIndex()) {
        seen.getOrPut(tokens[i]) { label }
        if (historyBeats != null && historyBeats[i] > 0) lengths.getOrPut(tokens[i]) { ArrayList() }.add(historyBeats[i])
    }
    val last = real.lastOrNull()
    val predictions = model.top(tokens, k).map { candidate ->
        val label = seen[candidate.token] ?: tokenLabel(candidate.token, key)
        val reasons = ArrayList<String>()
        if (candidate.cacheCount > 0) reasons.add("followed this context ${candidate.cacheCount}× earlier in the song")
        if (last != null) transitionReason(last, label, key)?.let { reasons.add(it) }
        if (reasons.isEmpty()) reasons.add("common continuation in the training corpus")
        val beats = lengths[candidate.token]?.let { median(it.toDoubleArray()) }
        Prediction(label, displayName(label, flats = key.flats), roman(label, key), pyRound(candidate.p, 4),
                   reasons.joinToString("; "), candidate.cacheCount, beats)
    }
    val prior = model.corpusDistribution(tokens).entries.sortedByDescending { it.value }.take(k)
        .map { (t, p) -> PriorEntry(roman(tokenLabel(t, key), key), pyRound(p, 4)) }
    return predictions to prior
}
```

```kotlin
import kotlin.math.max
import kotlin.math.min

// Chord segments from chordify_core/decode.py: grouping decoded units, merging fragments.

data class Segment(
    val start: Double,
    val end: Double,
    val index: Int, // vocabulary class
    val confidence: Double, // mean frame posterior of the chosen class
    val alternatives: List<Pair<Int, Double>> = emptyList(),
) {
    val duration: Double get() = end - start
}

/** Mean of the frames whose centres fall in [start, end); the nearest frame when none does. */
fun meanOver(posteriors: Array<DoubleArray>, frameTimes: DoubleArray, start: Double, end: Double): DoubleArray {
    val inside = frameTimes.indices.filter { frameTimes[it] >= start && frameTimes[it] < end }
    if (inside.isNotEmpty()) {
        val out = DoubleArray(posteriors[0].size)
        for (t in inside) for (c in out.indices) out[c] += posteriors[t][c]
        for (c in out.indices) out[c] /= inside.size.toDouble()
        return out
    }
    val middle = (start + end) / 2
    var nearest = 0
    for (t in 1 until frameTimes.size) {
        if (abs(frameTimes[t] - middle) < abs(frameTimes[nearest] - middle)) nearest = t
    }
    return posteriors[nearest].copyOf()
}

/** Add a slash bass from the bass head (12 pitch classes + 'none'): when its most likely note is a
 *  chord tone other than the root with probability >= [threshold]. */
fun inversion(label: String, bassProbs: DoubleArray, threshold: Double): String {
    val pc = argmax(bassProbs, until = 12)
    return if (bassProbs[pc] < threshold) label else withBass(label, pc)
}

/** numpy's `rows[from:until].mean(axis=0)`. */
internal fun meanRows(rows: Array<DoubleArray>, from: Int, until: Int): DoubleArray {
    val out = DoubleArray(rows[from].size)
    for (r in from until until) {
        val row = rows[r]
        for (c in out.indices) out[c] += row[c]
    }
    val n = (until - from).toDouble()
    for (c in out.indices) out[c] /= n
    return out
}

/** numpy's `posteriors[span, column].mean()`. */
private fun columnMean(posteriors: Array<DoubleArray>, span: Span, column: Int): Double {
    var sum = 0.0
    for (r in span.start until span.stop) sum += posteriors[r][column]
    return sum / (span.stop - span.start)
}

/** Confidence of [index] over [frames], and the [nAlternatives] most likely other classes. */
internal fun segmentStats(posteriors: Array<DoubleArray>, frames: Span, index: Int,
                          nAlternatives: Int): Pair<Double, List<Pair<Int, Double>>> {
    val mean = meanRows(posteriors, frames.start, frames.stop)
    // numpy's argsort(mean)[::-1]: ascending (equal values in index order), then reversed
    val order = mean.indices.sortedWith(compareBy<Int>({ mean[it] }, { it })).reversed()
        .filter { it != index }.take(nAlternatives)
    return mean[index] to order.map { it to mean[it] }
}

internal fun toSegments(path: IntArray, boundaries: DoubleArray, spans: List<Span>, posteriors: Array<DoubleArray>,
                        nAlternatives: Int): List<Segment> {
    val segments = ArrayList<Segment>()
    var start = 0
    for (u in 1..path.size) {
        if (u == path.size || path[u] != path[start]) {
            val frames = Span(spans[start].start, spans[u - 1].stop)
            val (confidence, alternatives) = segmentStats(posteriors, frames, path[start], nAlternatives)
            segments.add(Segment(boundaries[start], boundaries[u], path[start], confidence, alternatives))
            start = u
        }
    }
    return segments
}

/** Absorb segments shorter than [minUnits] units into the neighbour whose class has more
 *  posterior mass over the fragment. */
fun mergeShort(segments: List<Segment>, boundaries: DoubleArray, minUnits: Int, posteriors: Array<DoubleArray>,
               frameRate: Double, nAlternatives: Int = 3, frameOffset: Double? = null): List<Segment> {
    if (minUnits <= 1 || segments.size < 2) return segments
    fun units(seg: Segment): Int = searchSorted(boundaries, seg.end - 1e-6) - searchSorted(boundaries, seg.start - 1e-6)
    val offset = frameOffset ?: (0.5 / frameRate)
    val last = posteriors.size - 1
    val frames = { start: Double, end: Double ->
        val first = min(last, max(0, pyRoundToInt((start - offset) * frameRate + 0.5)))
        Span(first, min(last + 1, max(first + 1, pyRoundToInt((end - offset) * frameRate + 0.5))))
    }
    var out = segments.toMutableList()
    var changed = true
    while (changed && out.size > 1) {
        changed = false
        for (i in out.indices) {
            val seg = out[i]
            if (units(seg) >= minUnits) continue
            val span = frames(seg.start, seg.end)
            val j = listOf(i - 1, i + 1).filter { it in out.indices }.maxBy { columnMean(posteriors, span, out[it].index) }
            val keep = out[j]
            val start = min(keep.start, seg.start)
            val end = max(keep.end, seg.end)
            val (confidence, alternatives) = segmentStats(posteriors, frames(start, end), keep.index, nAlternatives)
            out[j] = Segment(start, end, keep.index, confidence, alternatives)
            out.removeAt(i)
            out = coalesce(out, posteriors, frames, nAlternatives)
            changed = true
            break
        }
    }
    return out
}

/** Join neighbours that ended up with the same chord after a merge. */
private fun coalesce(segments: List<Segment>, posteriors: Array<DoubleArray>, frames: (Double, Double) -> Span,
                     nAlternatives: Int): MutableList<Segment> {
    val out = ArrayList<Segment>()
    for (seg in segments) {
        val previous = out.lastOrNull()
        if (previous != null && previous.index == seg.index) {
            val (confidence, alternatives) = segmentStats(posteriors, frames(previous.start, seg.end), seg.index, nAlternatives)
            out[out.size - 1] = Segment(previous.start, seg.end, seg.index, confidence, alternatives)
        } else {
            out.add(seg)
        }
    }
    return out
}
```

```kotlin
package com.arbaba.chordifymobile.engine.decode

import com.arbaba.chordifymobile.engine.util.median
import com.arbaba.chordifymobile.engine.util.pyRoundToInt
import com.arbaba.chordifymobile.engine.util.searchSorted
import kotlin.math.ceil
import kotlin.math.ln
import kotlin.math.max
import kotlin.math.min
import kotlin.math.pow

// Port of chordify_core/decode.py: from frame posteriors to a chord timeline.
//  1. Pool frame log-posteriors per beat (chords change on beats).
//  2. Divide by class priors (hybrid NN/HMM scaling) so frequent classes are not favoured.
//  3. Viterbi with a per-step probability of staying (from the boundary head or a prior) and a
//     chord-to-chord matrix for changes (from the progression model).
//  4. Group into segments with confidence and alternatives, merge fragments.
// Posteriors are (frames, classes) arrays of doubles, as numpy float64 arrays are in Python.

internal const val EPS = 1e-9

/** A run of frames [start, stop), like a Python slice. */
data class Span(val start: Int, val stop: Int)

/** Boundaries of decoding units: beat intervals (optionally subdivided), or frames.
 *
 *  Before the first beat, after the last one and across gaps longer than 1.5 beats, the grid
 *  continues at the median beat period, so an intro, a break or a fade-out without beats is not
 *  decoded as one long unit. */
fun unitBoundaries(duration: Double, beats: DoubleArray?, frameRate: Double, subdivide: Int = 1): DoubleArray {
    if (beats == null || beats.size < 2) {
        val n = ceil(duration * frameRate).toInt()
        return DoubleArray(n + 1) { it / frameRate }
    }
    var grid = beats.filter { it > 0 && it < duration }.toDoubleArray()
    if (grid.size >= 2) {
        val period = median(DoubleArray(grid.size - 1) { grid[it + 1] - grid[it] })
        if (period > 0) {
            val head = arange(grid[0] - period, 0.0, -period).reversedArray()
            val tail = arange(grid.last() + period, duration, period)
            val gaps = ArrayList<Double>()
            for (i in 0 until grid.size - 1) {
                val a = grid[i]
                val b = grid[i + 1]
                if (b - a > 1.5 * period) {
                    val points = linspace(a, b, pyRoundToInt((b - a) / period) + 1)
                    for (k in 1 until points.size - 1) gaps.add(points[k])
                }
            }
            grid = (head + grid + tail + gaps.toDoubleArray()).distinct().sorted().toDoubleArray()
        }
    }
    val points = ArrayList<Double>()
    points.add(0.0)
    for (i in 0 until grid.size - 1) {
        val a = grid[i]
        val b = grid[i + 1]
        for (s in 0 until subdivide) points.add(a + (b - a) * s / subdivide)
    }
    points.add(grid.last())
    if (duration - grid.last() > 1e-3) points.add(duration)
    // numpy.round(points, 6), then numpy.unique
    var result = points.map { Math.rint(it * 1e6) / 1e6 }.distinct().sorted().toDoubleArray()
    if (result[0] > 0) result = doubleArrayOf(0.0) + result
    return result
}

/** Mean log-probability per unit; units that contain no frame centre borrow the nearest frame.
 *  Frame i is centred at `frameOffset + i / frameRate` (default: the middle of [i, i+1) / fps). */
fun pool(logProbs: Array<DoubleArray>, frameRate: Double, boundaries: DoubleArray,
         frameOffset: Double? = null): Pair<Array<DoubleArray>, List<Span>> {
    val nFrames = logProbs.size
    val offset = frameOffset ?: (0.5 / frameRate)
    val centres = DoubleArray(nFrames) { offset + it / frameRate }
    val pooled = ArrayList<DoubleArray>()
    val spans = ArrayList<Span>()
    for (u in 0 until boundaries.size - 1) {
        var s = searchSorted(centres, boundaries[u])
        var e = searchSorted(centres, boundaries[u + 1])
        if (e <= s) {
            s = min(s, nFrames - 1)
            e = s + 1
        }
        spans.add(Span(s, e))
        pooled.add(meanRows(logProbs, s, e))
    }
    return pooled.toTypedArray() to spans
}

/** Log-linear pooling of the prior stay probability and the boundary head:
 *  stay ∝ selfProb^(1-w) · (1-p)^w, change ∝ (1-selfProb)^(1-w) · p^w. */
fun combineStay(selfProb: Double, pChange: Double, weight: Double): Double {
    val stay = selfProb.pow(1 - weight) * (1 - pChange).pow(weight)
    val change = (1 - selfProb).pow(1 - weight) * pChange.pow(weight)
    return stay / (stay + change)
}

fun uniformChangeMatrix(nClasses: Int): Array<DoubleArray> =
    Array(nClasses) { i -> DoubleArray(nClasses) { j -> if (i == j) 0.0 else 1.0 / (nClasses - 1) } }

/** Best state path. `stay[t]` is P(no change entering step t); a change goes i -> j with
 *  probability `(1 - stay[t]) * changeMatrix[i][j]` (rows sum to 1, zero diagonal). */
fun viterbi(logEmissions: Array<DoubleArray>, stay: DoubleArray, changeMatrix: Array<DoubleArray>): IntArray {
    val nSteps = logEmissions.size
    val nStates = logEmissions[0].size
    val logChange = Array(nStates) { i ->
        DoubleArray(nStates) { j -> if (i == j) Double.NEGATIVE_INFINITY else ln(changeMatrix[i][j] + EPS) }
    }
    var score = DoubleArray(nStates) { logEmissions[0][it] - ln(nStates.toDouble()) }
    val back = Array(nSteps) { IntArray(nStates) }
    for (t in 1 until nSteps) {
        val s = stay[t].coerceIn(1e-6, 1 - 1e-6)
        val logStay = ln(s)
        val logMove = ln(1 - s)
        val next = DoubleArray(nStates)
        for (j in 0 until nStates) {
            var bestFrom = 0
            var bestChange = score[0] + logMove + logChange[0][j]
            for (i in 1 until nStates) {
                val candidate = score[i] + logMove + logChange[i][j]
                if (candidate > bestChange) {
                    bestChange = candidate
                    bestFrom = i
                }
            }
            val stayScore = score[j] + logStay
            if (stayScore >= bestChange) {
                back[t][j] = j
                next[j] = stayScore + logEmissions[t][j]
            } else {
                back[t][j] = bestFrom
                next[j] = bestChange + logEmissions[t][j]
            }
        }
        score = next
    }
    val path = IntArray(nSteps)
    var best = 0
    for (j in 1 until nStates) if (score[j] > score[best]) best = j
    path[nSteps - 1] = best
    for (t in nSteps - 1 downTo 1) path[t - 1] = back[t][path[t]]
    return path
}

/** Decode (T, V) frame posteriors into chord segments.
 *
 *  [changeProb] (T) is the boundary head's P(chord change at frame t); when given, each unit's
 *  stay probability pools `1 - max(changeProb near its start)` with [selfProb] (see
 *  [combineStay]). [changeMatrix] (V, V) is the transition prior for changes (e.g. from the
 *  progression model); uniform when null. [frameOffset] is the centre time of frame 0
 *  (`FeatureSpec.offset`); [duration] the audio length (default: the span of the frames). */
fun decode(
    posteriors: Array<DoubleArray>,
    frameRate: Double,
    beats: DoubleArray? = null,
    changeProb: DoubleArray? = null,
    prior: DoubleArray? = null,
    alpha: Double = 0.5,
    selfProb: Double? = null,
    changeMatrix: Array<DoubleArray>? = null,
    subdivide: Int = 1,
    minUnits: Int = 1,
    nAlternatives: Int = 3,
    boundaryWeight: Double = 0.5,
    frameOffset: Double? = null,
    duration: Double? = null,
): List<Segment> {
    val nFrames = posteriors.size
    val nClasses = posteriors[0].size
    val length = duration ?: (nFrames / frameRate + (if (frameOffset == null) 0.0 else frameOffset - 0.5 / frameRate))
    val logProbs = Array(nFrames) { t -> DoubleArray(nClasses) { ln(posteriors[t][it] + EPS) } }
    val boundaries = unitBoundaries(length, beats, frameRate, subdivide)
    val (pooled, spans) = pool(logProbs, frameRate, boundaries, frameOffset)
    if (prior != null) {
        for (row in pooled) for (c in row.indices) row[c] -= alpha * ln(prior[c] + EPS)
    }
    val unitsAreFrames = beats == null || beats.size < 2
    val stayProb = selfProb ?: if (unitsAreFrames) 0.97 else 0.75
    val stay = DoubleArray(spans.size) { stayProb }
    if (changeProb != null) {
        val clipped = DoubleArray(changeProb.size) { changeProb[it].coerceIn(1e-4, 1 - 1e-4) }
        for ((u, span) in spans.withIndex()) {
            val lo = max(0, span.start - 1)
            val hi = min(nFrames, span.start + 2)
            stay[u] = combineStay(stayProb, (lo until hi).maxOf { clipped[it] }, boundaryWeight)
        }
    }
    val path = viterbi(pooled, stay, changeMatrix ?: uniformChangeMatrix(nClasses))
    val segments = toSegments(path, boundaries, spans, posteriors, nAlternatives)
    return mergeShort(segments, boundaries, minUnits, posteriors, frameRate, nAlternatives, frameOffset)
}

/** numpy's `arange(start, stop, step)` for doubles, filled the way numpy fills it. */
private fun arange(start: Double, stop: Double, step: Double): DoubleArray {
    val n = ceil((stop - start) / step).toInt()
    if (n <= 0) return DoubleArray(0)
    val out = DoubleArray(n)
    out[0] = start
    if (n > 1) {
        out[1] = start + step
        val delta = out[1] - out[0]
        for (i in 2 until n) out[i] = start + i * delta
    }
    return out
}

/** numpy's `linspace(start, stop, num)`: `i * step + start`, with the last value exactly `stop`. */
private fun linspace(start: Double, stop: Double, num: Int): DoubleArray {
    val step = (stop - start) / (num - 1)
    return DoubleArray(num) { if (it == num - 1) stop else it * step + start }
}
```
